# أمثلة على الطلب

لا تحتاج برومبتًا طويلًا. أعطِ الوكيل الرابط، وقل ما تريد بكلامك، وهو سيسألك عن الباقي.

## من مجلد فارغ (الأسهل)
```
https://github.com/motalim-ai/motion-starter-kit
أريد فيديو مدته 30 ثانية عن فوائد شرب الماء، بستايل plotter الموجود في الريبو.
```

أمثلة أخرى:
```
https://github.com/motalim-ai/motion-starter-kit

```
```

أريد إعلانًا مدته 20 ثانية لتطبيقي، بستايل plotter، وبشكل طولي للريلز.
```

## بفيديو من عندك
انسخ الريبو، وضع الفيديو في `reference/`، ثم قل:
```
في مجلد reference فيديو يعجبني. أريد فيديو جديدًا بنفس أسلوبه عن ...
```

## ماذا سيحدث
- يسألك الوكيل ما ينقصه، مرة واحدة: الموضوع، والمدة، واللغة، والتعليق الصوتي، والموسيقى، والمؤثرات. جاوبه بكلامك العادي.
- يبني الفيديو، ثم يفتح لك Remotion Studio لتشاهده.

## بعد أن تشاهده
قل ما تريد تغييره بكلامك العادي. أمثلة:
- «الكلام يظهر بسرعة، اجعل كل جملة تبقى أطول.»
- «اجعل هذا الانتقال أنعم.»
- «غيّر اللون المميز إلى الأزرق.»
- «الموسيقى عالية، اخفضها.»

وعندما يعجبك:
```
رندر.
```
