# Lesson video style (from references 1 and 2, adapted to the Algerian math lessons)

Format: 9:16 for reels (short lessons, one idea) — 16:9 for full lessons (teacher's rule: one 16:9 version unless asked).

Layout (9:16): top = progress dots + two-font title; middle = rule / formula / graph card; bottom = presenter on a gold half-circle.
Palette: navy #0A1638 + gold #F5B54A (series identity), cream cards, red only for "wrong", green ✓ for "right".
Fonts: Tajawal ExtraBold (titles), Amiri (body Arabic), KaTeX/MathJax (math), Poppins (numbers/Latin).

Beats (≈ 2–2.5 s each):
1. Hook (3 s): question or "N mistakes" grid.
2. Chapter tag «01 // التذكير» → card.
3. Rule card lands + key word highlighted as spoken.
4. Wrong way chip crossed out → right way card + ✓.
5. Worked example: formula steps morph one into the next (MathJax/Manim TransformMatchingTex).
6. Graph / sign table / space figure (Manim or GeoGebra).
7. «حاول بنفسك» pause card with a timer.
8. Recap map (خلاصة الطرائق) around the result.
9. CTA: comment keyword → gift card + WhatsApp button click.

Rules: every formula verified (sympy) before recording; text on screen = spoken text; one idea per screen; no AI-generated characters or video (presenter = teacher or a code-drawn avatar).
